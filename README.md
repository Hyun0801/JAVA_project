# 📺 OTT 구독 관리 프로그램

> 여러 OTT 서비스의 구독 정보를 통합 관리하고, AI 기반 자동 등록 및 결제일 알림을 통해 효율적인 구독 관리를 지원하는 프로그램입니다.

## 1. 프로젝트 소개

### 📌 프로젝트 개요

최근 넷플릭스, 디즈니+, 티빙 등 다양한 OTT 서비스의 이용이 증가하면서 여러 구독 서비스를 동시에 관리하는 경우가 많아지고 있습니다.

하지만 각 서비스의 결제일이 다르기 때문에 결제 시점을 놓치거나 사용하지 않는 서비스에 비용을 지출하는 문제가 발생할 수 있습니다.

본 프로젝트는 사용자가 이용 중인 OTT 서비스와 구독 정보를 통합 관리하고, LLM API를 활용한 자연어 기반 구독 정보 자동 등록 및 결제일 알림 기능을 제공하여 효율적인 구독 관리와 합리적인 소비를 돕는 것을 목표로 합니다.

### 🎯 개발 목적
- 여러 OTT 서비스의 구독 정보를 한곳에서 관리
- 자연어 입력을 통한 간편한 구독 정보 자동 등록
- 월별 구독 지출을 확인하여 소비 현황 파악
- 결제 예정일 알림을 통한 결제일 관리
- 불필요한 구독으로 인한 지출 방지

## 2. 주요 기능

| 기능 | 설명 |
|---|---|
| 구독 정보 자동 등록 | LLM API를 활용하여 자연어 입력에서 서비스명, 결제 금액, 결제일 등을 추출하고 자동 저장 |
| 구독 목록 조회 | 등록된 OTT 서비스와 결제 정보 확인 |
| 월별 지출 관리 | 월간 구독 서비스 이용 금액 확인 |
| 결제일 알림 | 결제 예정일에 Discord 알림 전송 |
| 결제일 자동 확인 | 스케줄러를 활용한 결제 예정일 자동 확인 |
| 구독 취소 안내 | 각 OTT 서비스의 공식 관리 페이지 연결 |

### 🤖 대화형 구독 정보 자동 등록

사용자가 Discord 챗봇에 자연어로 구독 정보를 입력하면 LLM API가 입력 내용을 분석하여 필요한 정보를 자동으로 추출합니다.

**입력 예시**
```text
넷플릭스 프리미엄 17,000원 다음 달 5일 결제
```

**처리 과정**
1. 사용자가 Discord 챗봇에 자연어로 구독 정보 입력
2. LLM API가 입력 내용을 분석
3. 서비스명, 결제 금액, 결제일 등의 정보 추출
4. 추출한 정보를 구조화하여 SQLite 데이터베이스에 저장

이를 통해 사용자가 직접 항목별 정보를 입력해야 하는 번거로움을 줄이고 간편하게 구독 정보를 등록할 수 있습니다.

## 4. 시스템 구성

### 🖥️ Java Swing
- 구독 목록 조회
- 월별 구독 지출 확인
- 구독 정보 관리

### 💾 SQLite
- OTT 구독 정보 저장
- 서비스명, 결제 금액, 결제일 등 데이터 관리

### 🤖 Discord Bot
- 자연어 기반 구독 정보 입력
- LLM API를 활용한 구독 정보 자동 등록
- 결제 예정일 알림 전송

### 🧠 LLM API
- 사용자의 자연어 입력 분석
- 서비스명, 결제 금액, 결제일 추출
- 추출한 정보를 데이터베이스 저장 형식으로 구조화

### ⏰ Scheduler
- 일정한 주기로 구독 결제일 확인
- 결제 예정일에 맞춰 Discord 알림 전송

## 5. 기대 효과

- 여러 OTT 서비스의 구독 정보를 통합하여 편리하게 관리할 수 있습니다.
- 자연어 입력을 통해 구독 정보를 간편하게 등록할 수 있습니다.
- 월별 구독 지출을 확인하여 소비 습관을 파악할 수 있습니다.
- 결제일 알림을 통해 예상하지 못한 자동 결제를 예방할 수 있습니다.
- 사용하지 않는 구독 서비스를 확인하고 불필요한 지출을 줄일 수 있습니다.

## 8. 프로젝트 진행

본 프로젝트는 Java를 활용한 OTT 구독 관리 프로그램 개발을 목적으로 진행되었습니다.

Java Swing 기반의 관리 화면과 SQLite 데이터베이스를 연동하고, Discord 챗봇 및 LLM API를 활용하여 자연어 기반 구독 정보 자동 등록과 결제일 알림 기능을 구현합니다.
